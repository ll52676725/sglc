# 时光簿 - 产品需求文档（优化版）

## 1. 产品概述

**"时光簿"** —— 一个个人记忆管理与传记生成平台。帮助用户收集、整理生活中的珍贵照片与视频，记录每一个重要时刻，最终通过AI将这些碎片化记忆编织成可阅读、可传承的个人传记。

- **目标用户**：注重家庭记忆保存的个人用户，希望为未来留下人生故事的所有年龄段用户
- **核心价值**：将碎片化的生活记忆系统化整理，通过AI技术转化为可阅读、可分享的个人传记
- **Slogan**：记录此刻，成书未来

---

## 2. 现状问题分析

### 2.1 当前功能堆砌问题

| 问题点 | 具体表现 | 影响 |
|--------|----------|------|
| **导航逻辑混乱** | 5个功能平级排列（时光动态/相册/AI分类/上传/传记），缺乏用户旅程引导 | 用户不知道从何开始，功能之间割裂 |
| **入口重复** | 发布动态有两个入口：时光动态页的"记录此刻" + 上传页的"同步到时光动态" | 用户困惑，操作路径不统一 |
| **数据流向不清晰** | 上传媒体后，用户不知道媒体去了哪里，也不知道下一步该做什么 | 流失率高，用户无法形成使用习惯 |
| **AI功能孤立** | AI分类和传记生成是两个独立页面，没有关联引导 | 用户不知道AI分析结果可以用来生成传记 |
| **缺少引导** | 新用户进入后没有明确的使用指引 | 留存困难 |

### 2.2 核心流程问题

**当前别扭的流程：**
```
用户打开应用 → 看到5个平级菜单 → 不知道点哪个
  → 点"上传" → 上传完跳转到时间线或相册 → 结束
  → 点"时光动态" → 发动态 → 结束
  → 点"传记" → 选时间范围生成 → 结束
```

**问题：** 没有形成"收集 → 整理 → 沉淀 → 生成"的闭环体验

## 3. 优化后产品架构

### 3.1 核心用户旅程（主线）

```
收集记忆 → 智能整理 → 沉淀故事 → 生成传记
    ↓          ↓          ↓          ↓
  上传媒体   AI分类      时光动态    传记工坊
  发动态     相册管理    标签管理    导出分享
```

### 3.2 功能模块重组

| 模块层级 | 一级模块 | 二级功能 | 说明 |
|----------|----------|----------|------|
| **L1** | 📸 **记忆收集** | 上传媒体 | 照片/视频/语音批量上传 |
| | | 发布动态 | 文字+心情+天气+媒体的时光记录 |
| **L1** | 🗂️ **智能整理** | AI智能分类 | 人物/地点/事件/时间维度自动分组 |
| | | 相册管理 | 手动创建和管理相册，AI推荐相册 |
| | | 媒体详情 | 查看、编辑元数据、关联标签 |
| **L1** | 📖 **传记工坊** | 生成传记 | AI基于素材自动生成个人传记 |
| | | 续写编辑 | 在线编辑、续写传记 |
| | | 导出分享 | PDF/Word导出 |
| **L1** | 👤 **个人中心** | 数据统计 | 记忆数据概览 |
| | | 设置 | 偏好设置 |

## 4. 详细功能需求

### 4.1 记忆收集（首页）

**定位：** 用户打开应用的第一页，引导用户快速记录和上传。

#### 4.1.1 页面布局

```
┌─────────────────────────────────────────────────────┐
│  📸 记忆收集                    [统计卡片：X张照片 X条动态] │
├─────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐ │
│  │   发布动态    │  │  上传媒体     │  │  语音记录     │ │
│  │   快捷入口    │  │  快捷入口     │  │  快捷入口     │ │
│  └──────────────┘  └──────────────┘  └──────────────┘ │
├─────────────────────────────────────────────────────┤
│  ⏱️ 最近动态（时光流）                                │
│  [动态卡片1]                                         │
│  [动态卡片2]                                         │
│  ...                                                │
└─────────────────────────────────────────────────────┘
```

#### 4.1.2 功能详情

**1. 快捷操作区（3个大卡片）**

| 功能 | 交互 | 说明 |
|------|------|------|
| **发布动态** | 点击弹出发布弹窗 | 文字+心情+天气+位置+标签，可附加媒体 |
| **上传媒体** | 点击进入上传页 / 拖拽文件直接上传 | 照片视频批量上传 |
| **语音记录** | 点击开始录音 | 语音转文字（可选），自动保存为动态 |

**2. 最近动态流**
- 按时间倒序展示最近发布的动态
- 支持年份筛选
- 每条动态显示：心情emoji、文字内容、媒体预览、时间、位置、标签

#### 4.1.3 发布动态弹窗

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 内容 | 多行文本 | 是 | 此刻的想法和故事 |
| 心情 | 单选（emoji） | 否 | 12种心情选项 |
| 天气 | 单选（emoji） | 否 | 8种天气选项 |
| 位置 | 文本输入 | 否 | 自动获取或手动输入 |
| 时间 | 日期时间选择 | 是 | 默认当前时间，可修改 |
| 标签 | 多选/新增 | 否 | 可添加自定义标签 |
| 媒体 | 图片/视频/语音 | 否 | 可多选，支持预览和删除 |

### 4.2 智能整理

**定位：** 帮助用户把零散的媒体整理成体系。

#### 4.2.1 页面布局（Tab切换）

```
┌─────────────────────────────────────────────────────┐
│  🗂️ 智能整理                                         │
│  ┌────────┬────────┬────────┬────────┐              │
│  │ AI分类  │  相册  │ 全部媒体 │ 标签  │              │
│  └────────┴────────┴────────┴────────┘              │
├─────────────────────────────────────────────────────┤
│  [对应Tab的内容区]                                   │
└─────────────────────────────────────────────────────┘
```

#### 4.2.2 Tab1: AI智能分类

**功能：**
- AI自动分析所有媒体的元数据
- 按8个维度分组展示：
  - 👥 **人物**：基于人物标签分组
  - 📍 **地点**：基于拍摄地点分组
  - 📅 **事件**：基于描述和标签识别的事件
  - 🏷️ **标签**：自定义标签分组
  - 🌱 **季节**：春夏秋冬
  - ⏰ **时段**：早晨/上午/下午/晚上
  - 📆 **月份**：按月份分组
  - 📊 **年份**：按年份分组

**交互亮点：**
- 每个分组卡片显示预览图+数量
- 点击分组进入详情，展示该分组下所有媒体
- 右上角「一键创建相册」：AI自动推荐相册，用户确认后创建

**AI洞察区：**
- 显示AI分析出的有趣结论
  - 例："你在2024年夏天拍摄了最多的照片"
  - 例："你最喜欢在周末记录生活"
  - 例："旅行是你最常记录的主题"

#### 4.2.3 Tab2: 相册

**功能：**
- 相册列表卡片展示（封面、名称、数量、时间范围）
- 「+ 创建相册」按钮
- 相册详情：网格展示媒体，支持批量操作

#### 4.2.4 Tab3: 全部媒体

**功能：**
- 网格展示所有媒体
- 支持筛选（类型：照片/视频/语音）
- 支持排序（时间正序/倒序）
- 支持批量选择（加入相册、删除、添加标签）

#### 4.2.5 Tab4: 标签管理

**功能：**
- 所有标签的云图展示
- 点击标签查看关联的媒体和动态
- 支持重命名、删除、合并标签

│              │                                      │

#### 4.3.2 创建传记向导（Step by Step）

**Step 1: 选择素材范围**
- 时间范围选择（开始日期 - 结束日期）
- 素材来源：
  - ☐ 全部时光动态
  - ☐ 指定相册（可多选）
  - ☐ 指定标签（可多选）
- 显示预计素材数量："将基于 X 条动态、Y 张照片生成"

**Step 2: 选择风格**
- 8种风格卡片选择（大卡片预览）
  - 📜 正式 - 正式庄重的叙事风格
  - 📔 轻松 - 轻松愉快的日记风格
  - 🌸 诗意 - 优美诗意的文学风格
  - 🏙️ 现代 - 现代都市小说风格
  - ⚔️ 武侠 - 江湖武侠传奇风格
  - 💕 浪漫 - 浪漫爱情故事风格
  - ✨ 奇幻 - 奇幻冒险魔法风格
  - 📖 回忆录 - 深情回忆录风格
- 每种风格显示示例段落预览

**Step 3: 选择叙述视角**
- 第一人称（"我..."）
- 第三人称（"他/她..."）
- 参考作家风格（可选）：
  - 金庸、余华、张爱玲、村上春树等

**Step 4: 生成中...**
- 进度动画：正在分析素材 → 正在构思章节 → 正在撰写
- 生成时间预估

- 优雅的排版，章节分明

- 章节标题可编辑

**操作按钮：**

## 5. 核心流程优化

### 5.1 新用户引导流程

```
用户首次打开
    ↓
欢迎页："欢迎来到时光簿，让我们一起记录你的故事"
    ↓
3个引导卡片：
  1. 📸 上传你的第一批照片
  2. ✍️ 写下第一条动态
  3. ✨ 体验AI生成传记
    ↓
用户选择任意入口开始使用
```

### 5.2 记忆收集闭环

```
用户进入「记忆收集」
    ↓

    ↓
完成后
    ↓
智能推荐下一步：
  "你上传了10张旅行照片，要创建一个旅行相册吗？"
  "你记录了很多美食，要查看AI分类吗？"
  "你已经积累了30条动态，要试试生成传记吗？"
```

### 5.3 从素材到传记的转化路径

```
上传媒体 → 自动进入时间线
    ↓
AI智能分类 → 发现规律 → 推荐创建相册
    ↓
积累足够素材 → 提示"可以生成传记了"
    ↓
进入传记工坊 → 一键生成
    ↓
导出分享 → 获得成就感
    ↓
激励继续记录 → 形成正向循环
```

## 6. 数据模型（保持现有，优化关联）

### 6.1 实体关系

```
MediaItem(媒体) ──n:n── Album(相册)
    │
    │ 1:n
    ↓
Moment(动态) ── 包含文字、心情、天气、标签
    │
    │ 被引用
    ↓
Biography(传记) ── 包含多个Chapter(章节)
    ↑
    │ 引用
AI分类结果
```

### 6.2 关键关联优化

- **MediaItem** 增加 `momentId` 字段，明确该媒体属于哪条动态
- **Moment** 增加 `aiTags` 字段，存储AI自动提取的标签
- **BiographyChapter** 明确关联 `momentIds` 和 `mediaIds`，点击可回溯原始素材

## 7. 界面设计优化建议

### 7.1 视觉风格（保持现有）

- 主色调：暖棕金 + 象牙白
- 字体：标题衬线体，正文无衬线
- 氛围：温暖、怀旧、优雅

### 7.2 交互优化点

1. **操作反馈**：每个操作完成后给予明确的成功提示和下一步引导
2. **空状态设计**：每个页面的空状态都应该引导用户进行下一步操作
3. **进度可视化**：上传、生成传记等耗时操作显示清晰的进度
4. **快捷操作**：常用操作放在最显眼的位置

### 7.3 空状态示例

**记忆收集页（无动态）：**
```
✨ 还没有记录
"每一个平凡的日子，都值得被记住"

[发布第一条动态]  [上传第一批照片]
```

**传记工坊（无传记）：**
```
📖 你的故事等待被书写
"积累足够的时光记录，AI将为你生成独一无二的个人传记"

  进度条：■■□□□ 40% （已记录12条动态，还需18条可生成传记）

[去记录时光]
```

## 10. 总结

本次优化的核心思路：
1. **从功能堆砌 → 用户旅程引导**：让用户清晰地知道"我现在该做什么"
2. **从孤立功能 → 闭环体验**：收集 → 整理 → 沉淀 → 生成，形成正向循环
3. **从被动使用 → 主动激励**：每一步操作都有反馈和下一步建议
4. **从工具属性 → 情感价值**：让用户感受到"记录是有意义的"

通过这些优化，时光簿将从一个"照片管理工具"升级为一个"有温度的个人记忆管家"。
